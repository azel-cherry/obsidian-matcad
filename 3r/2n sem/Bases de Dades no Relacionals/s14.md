# Neo4j: Primera entrega

1. ***Director de la pel·lícula "The Devil's Advocate".***
```cypher
match (p:Person) -[:DIRECTED]-> (:Movie {title: "The Devil's Advocate"})
return p.name as Director
```

2. ***Actors de "Cloud Atlas" i els seus rols.***
```cypher
match (p:Person) -[r:ACTED_IN]-> (:Movie {title: "Cloud Atlas"})
return p.name as Actor, r.roles as Roles
```

3. ***Actors que han treballat amb cada productor.***
```cypher
match (p:Person) -[:PRODUCED]-> (:Movie) <-[:ACTED_IN]- (a:Person)
return p.name as Producer, p.born as Born, collect(a.name) as Actors
```

4. ***Actors de "A Few Good Men" nascuts entre 1960 i 1970.***
```cypher
match (p:Person) -[:ACTED_IN]-> (:Movie {title: "A Few Good Men"})
where 1960 <= p.born <= 1970
return p.name as Actor, p.born as Born
```

5. ***Pel·lícules estrenades a partir del 2005.***
```cypher
match (m:Movie)
where m.released >= 2005
return m.title as Movie, m.released as Release
```

6. ***Pel·lícules que comencen per "The".***
```cypher
match (m:Movie)
where m.title starts with "The"
return m.title as Movie
```

7. ***Actors amb nom "Kevin", pel·lícules on han actuat i els seus rols.***
```cypher
match (p:Person) -[r:ACTED_IN]-> (m:Movie)
where p.name starts with "Kevin"
return p.name as Actor, collect({movie: m.title, roles: r.roles}) as `Movies and Roles`
```

8. ***Persones que han escrit una pel·lícula però no l'han produïda.***
```cypher
match (p:Person) -[:WROTE]-> (m:Movie)
where not exists((p)-[:PRODUCED]->(m))
return p.name as Writer, m.title as Movie
```

9. ***Pel·lícules estrenades el 2000, 2004 o 2006.***
```cypher
match (m:Movie)
where m.released in [2000, 2004, 2006]
return m.title as Movie, m.released as Release
```

10. ***Pel·lícules que ha dirigit "Lilly Wachowski", els anys que fa des de que es va estrenar, i l'edat de la Lily quan es va estrenar.***
```cypher
match (p:Person) -[:DIRECTED]-> (m:Movie)
where p.name = "Lilly Wachowski"
return
	m.title as Movie,
	m.released as Release,
	date().year - m.released as `Movie Age`,
	m.released - p.born as `Lily's Age`
```
