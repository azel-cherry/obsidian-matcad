### Creació de nodes

1. ***Afegir propietats "born" i "birthPlace" a "Robin Wright".***
	```cypher
	merge (r:Person {name: "Robin Wright"})
	set
		r.born = 1966,
		r.birthPlace = "Dallas"
	```

2. ***Noms i rols dels actors de "Forrest Gump".***
	```cypher
	match (:Movie {title: "Forrest Gump"}) <-[r:ACTED_IN]- (a:Person)
	return a.name as Actor, r.roles as Roles
	```

3. ***Afegir relació ACTED_IN de "Tom Hanks", "Gary Sinise" i "Robin Wright" amb "Forrest Gump".***
	```cypher
	merge (m:Movie {title: "Forrest Gump"});
	match (a:Person), (m:Movie {title: "Forrest Gump"})
	where a.name in ["Tom Hanks", "Gary Sinise", "Robin Wright"]
	merge (a) -[:ACTED_IN]-> (m)
	```


### *Constraints*

4. ***És possible crear una constraint UNIQUE amb l'atribut name de Person?***
	
	Sí que és possible. De fet, quan executem la següent comanda:
	
	```cypher
	create constraint personName if not exists
	for (p:Person) require p.name is unique
	```
	
	Obtenim el següent missatge: `Note: successful completion - index or constraint already exists`.
	
	És a dir que aquesta *constraint* ja existia i en aquesta base de dades actua com la ID de `Person`.

4. ***Fer més eficient la cerca per data de naixement.***
	
	La meva proposta és fer que la propietat `p.born` passi a ser una relació `:BORN` a un node `:Year`. D'aquesta manera, un cop s'han trobat els nodes dels anys desitjats, totes les persones que ho compleixen hi estan relacionades.
	```cypher
	match (p:Person)
	where p.born is not null
	merge (y:Year {value: p.born})
	merge (p) -[:BORN]-> (y)
	remove p.born
	```

6. ***Diferència entre EXPLAIN i PROFILE.***
	
	Les dues son eines per analitzar *queries*, però la diferència principal és que `EXPLAIN` no executa la consulta; només proporciona estimacions sobre el seu processament. En canvi, `PROFILE` sí que executa la *query*, i retorna informació real sobre la seva execució.
